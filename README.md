## 📌 Executive Summary

**CareerPath AI** is an intelligent, full-stack educational web application designed for college students and fresh graduates. It diagnoses the **skill-job mismatch paradox**, analyzes a student's academic background, identifies missing technical competencies, generates personalized 4/8/12-week learning roadmaps with free verified learning resources, conducts career skill quizzes, and tracks learning milestones in real time.

This project was built for the **IBM SkillsBuild Masterclass 5 Academic Assessment** and directly aligns with **United Nations Sustainable Development Goal 8: Decent Work and Economic Growth** (specifically Target 8.6: Substantially reduce youth not in employment, education, or training).

## 🚀 Key Features

### 🌟 Feature A: Professional Home Experience
- Clean, responsive landing page with custom blue-and-white theme and dark navy headings (`#0f172a`, `#1e3a8a`, `#2563eb`).
- Clear project explanation, hero CTA, interactive feature cards, how-it-works process, and dedicated UN SDG 8 impact module.
- Accessible navigation bar with mobile drawer toggle and academic project badges.
- Footer with interactive modals for About Project, Concept Note, Lean Canvas, Academic Contact, Privacy Policy, and LocalStorage details.

### 📝 Feature B: Career Profile Form
- Collects: Student Name (optional), Degree/Course, Current Skills, Experience Level, Target Career, Daily Study Time, and Roadmap Duration (4, 8, or 12 weeks).
- Dropdown includes popular tracks (Full Stack Web Developer, Data Scientist / AI Engineer, Cloud & DevOps Engineer, Cybersecurity Analyst, Mobile App Developer, UI/UX Designer & Frontend) plus a dynamic "Other / Custom Career" input.
- Real-time client-side validation with inline error feedback and red border highlights.
- **Viva Demo Chips:** 4 instant prefill buttons (`Web Developer`, `Data Scientist`, `DevOps`, `Cybersecurity`) for instant, one-click demonstration during academic vivas!

### 🤖 Feature C: AI-Powered Career Roadmap
- Powered by a secure backend endpoint: `POST /api/roadmap`.
- Integrated with **Google Gemini 2.5 Flash** using the official `@google/genai` SDK.
- Enforces strict JSON schema generation, returning:
  - Career Goal & Industry Outlook
  - Recognized Existing Skills vs. Recommended Missing Skills
  - Phased Weekly Schedule with Themes, Milestones, Topics, Hands-on Exercises, Capstone Projects, and Free Curated Resource Links (MDN, W3C, Kaggle, FreeCodeCamp).
- **Academic Transparency & Fallback:**
  - If a valid `GEMINI_API_KEY` is present: displays a glowing green badge `"✨ Generated by Google Gemini AI"`.
  - If the API key is not configured or the service is temporarily unreachable: smoothly serves a comprehensive, high-quality curated sample roadmap clearly labeled with an amber banner `"Curated Academic Sample Roadmap"`. **Never falsely claims sample data was generated by AI.**

### 🎯 Feature D: Career Skill Quiz
- 5 multiple-choice questions per career track (4 options each).
- Automatic grading, score calculation (e.g., `4/5`), and percentage display (`80%`).
- Detailed technical explanations for every question explaining why the correct answer is right.
- Retake Quiz button to reset and practice again.
- Automatically saves scores to the dashboard and persists in browser memory.

### 📈 Feature E: Milestone Task Tracker
- Aggregates actionable checkpoints from all weeks of the active roadmap.
- Checkboxes synchronized between the Weekly Timeline view and the Master Tracker.
- Filter tabs: **All Tasks**, **Pending Tasks**, and **Completed Tasks**.
- Dynamically updates completed/pending counts and the overall progress percentage.
- **Client-Side Persistence:** Persists data across browser refreshes using `Window.localStorage`.
- "Reset All Progress" button with an accessible confirmation dialog.

### 📊 Feature F: Real Dynamic Telemetry Dashboard
- Displays genuine, real-time data from user interactions:
  - Active Career Pathway
  - Overall Progress Percentage & Progress Bar Animation
  - Total Learning Tasks, Completed Tasks, and Pending Tasks
  - Latest Quiz Score & Grade
  - **Recommended Next Action:** Automatically scans sequential roadmap tasks, locates the first uncompleted milestone, and offers a **"Jump to Task"** button that scrolls and highlights the task.

## 💻 Local Setup & Run Guide

### Prerequisites
- [Node.js](https://nodejs.org/) (Version 18 or higher; recommended v20+ or v24 LTS)
- npm (comes bundled with Node.js)
- A modern web browser (Google Chrome, Firefox, Safari, or Edge)

### Step 1: Clone or Navigate to the Workspace
```bash
cd /Users/karankumar/Desktop/careerpath-ai
```

### Step 2: Install Dependencies
You can install dependencies from the root directory or inside `backend`:
```bash
# Option A: From root directory
npm install

# Option B: Or directly inside backend
cd backend && npm install && cd ..
```

### Step 3: Configure Environment Variables (Optional for AI)
To enable live AI roadmap generation with Google Gemini:
1. Copy `backend/.env.example` to `.env` (or `backend/.env`):
   ```bash
   cp backend/.env.example backend/.env
   ```
2. Open `backend/.env` and insert your free Gemini API key:
   ```env
   PORT=3000
   GEMINI_API_KEY=AIzaSy...your_actual_key_here
   ```
   > 💡 **Note:** You can obtain a free Gemini API key in 30 seconds at [Google AI Studio](https://aistudio.google.com/app/apikey).  
   > ⚠️ **No API Key? No Problem!** CareerPath AI features a complete, zero-configuration **Sample Roadmap Fallback**. If no key is provided, the application automatically supplies high-quality curated sample roadmaps and clearly labels them. All tracking, tasks, and quizzes work identically!

### Step 4: Start the Application Server
Run the start command from the project root:
```bash
npm start
```
You will see output indicating the server has initialized:
```text
====================================================
🚀 CareerPath AI Server running on port 3000
👉 Local: http://localhost:3000
👉 Static frontend directory: .../careerpath-ai/frontend
👉 Gemini Key Status: Configured ✅ (or using sample fallback)
====================================================
```

### Step 5: Open in Your Browser
Open your browser and navigate to:
```
http://localhost:3000
```

## 🌐 GitHub Upload & Render Deployment Guide

### Deploying to GitHub

1. Initialize Git in the project root (if not already done):
   ```bash
   cd /Users/karankumar/Desktop/careerpath-ai
   git init
   git add .
   git commit -m "Initial commit: CareerPath AI for IBM SkillsBuild Masterclass 5"
   ```

2. Create a new public repository on [GitHub](https://github.com/new) named `careerpath-ai`.

3. Push your repository:
   ```bash
   git remote add origin https://github.com/<your-username>/careerpath-ai.git
   git branch -M main
   git push -u origin main
   ```
   > 🔒 **Security Guarantee:** The `.gitignore` file automatically protects `.env` and `node_modules/`. Your API keys will never be committed to Git.

### Deploying to Render (Free Cloud Hosting)

1. Sign up or log in at [Render.com](https://render.com/).
2. In the Render Dashboard, click **New +** and select **Web Service**.
3. Connect your GitHub account and select the `careerpath-ai` repository.
4. Configure the Web Service settings:
   - **Name:** `careerpath-ai`
   - **Region:** Any region close to your users (e.g., Singapore, Frankfurt, or Oregon)
   - **Branch:** `main`
   - **Root Directory:** *(leave blank — root package.json handles everything)*
   - **Runtime:** `Node`
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Instance Type:** `Free`
5. In the **Environment Variables** section, add:
   - Key: `GEMINI_API_KEY`
   - Value: *(your Google Gemini API key)*
   - Key: `PORT`
   - Value: `5000` *(or let Render set PORT automatically)*
6. Click **Create Web Service**.
7. Render will build the project and deploy it to a live public URL: `https://careerpath-ai-xxxx.onrender.com`.
